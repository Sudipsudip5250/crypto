## Educational Purpose

This project is released strictly for **educational and research purposes**.
It demonstrates:

- Cross-platform process management in Python
- CPU temperature monitoring and thermal throttling
- Auto-updating binaries from GitHub releases
- CLI wrapper patterns across Bash, Batch, and PowerShell
- Daemon / background-process management

It is **not** intended to be a commercial mining tool.
